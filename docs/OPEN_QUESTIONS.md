## 백로그 (0.1.0 이후)

0.1.0 배포 전 재리뷰(Opus, effort high)에서 "배포 차단 없음"으로 판정된 후속 항목입니다.

- **[0.1.1 우선]** 편집기에서 렌더링 중(busy) "제보 취소"·Back을 누르면, 렌더링이 끝난 뒤 `writeArtifact`의 `mkdirs()`가 초안 디렉터리를 다시 만들어 버린 초안이 목록에 되살아납니다. `deleteDraft`에서 작업 취소, busy 동안 버튼 비활성화로 고칩니다.
- **[0.1.1 우선]** 상세 입력 → Back → Back을 누르면 제목·미디어가 있는 초안이 확인 없이 삭제됩니다. 다시 편집하면 주석(가림 포함)이 비어 있어, 다음을 누르면 가림 없는 스크린샷으로 바뀝니다. 검토 화면은 실제 파일을 보여 주므로 승인 불변식은 유지됩니다. 삭제 확인 대화상자와 주석 보존으로 고칩니다.
- 전송 중 "첨부됨/없음" 확인이 sender의 스냅샷 저장에 덮어써질 수 있습니다(보수적 방향). SENDING 동안 확인 버튼을 숨깁니다.
- 단일 전송 집합이 controller마다 따로 있습니다. runtime 수준으로 옮깁니다.
- "첨부됨" 확인으로 성공에 도달하면 원본 캡처가 TTL까지 남습니다. 성공 전이 시 삭제합니다.
- 이슈 키 정규식이 Jira 형식만 허용하고, 오류 메시지가 현지화되어 있지 않습니다.
- `addMedia` commit 실패 시 파일 정리, 초안 목록·`resolver.query`를 Main 밖으로 옮기기.
- vanniktech 0.35.0은 AGP 9.0.0 정식 지원 전 버전입니다. 0.36.0 이상으로 올립니다.
- **기능 아이디어**: 이미 올린 티켓에 대해서는 새 이슈 대신 해당 티켓의 **코멘트로 제보**하기. `IssueUploader`에 코멘트 추가 연산이 필요하고, 대상 이슈 선택 방식(키 입력·최근 제보 목록)을 정해야 합니다. 현재 설계의 "기존 이슈 수정 금지" 원칙과 맞추려면 코멘트 추가만 허용하고 본문 수정은 계속 제외합니다.
